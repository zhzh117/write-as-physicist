# Contributing

Contributions should help readers follow the physics and help authors preserve the meaning of their work. Useful changes include clearer instructions, corrected references, better examples, and more accurate installation guidance.

## Report a writing problem

Open an issue with enough context to reproduce the problem:

1. The writing task, audience, and output language.
2. A short source passage and the prompt used.
3. The relevant output and a specific explanation of what went wrong.
4. The host, model if known, and repository revision or download date.

Use material you can share publicly. A synthetic example is useful when a manuscript or dataset is confidential. For an installation problem, include the host version, folder layout, and error message.

## Propose a change

Keep each pull request focused on one issue. Explain the reason for the change, show the relevant before-and-after text, and describe how you checked it.

For changes to the writing guidance:

- Preserve the distinction between observations, calculations, inferences, and proposals.
- Retain qualifications that affect the evidence, scope, or interpretation.
- Choose examples across physics fields and identify illustrative numbers explicitly.
- Link added scientific claims to primary sources and record source details in `references/sources.md`.
- Keep the instructions concise and place extended examples in `references/examples.md`.

Keep repository documentation in English. Chinese passages may be used when the wording itself is the subject of an example.

## Check the change

Read the affected passage in context, check relative links and file paths, and preserve valid YAML frontmatter. When a change affects writing behavior, try a representative task and include the prompt, relevant input and output, and any material unresolved issue. Documentation-only changes need a content and link check.
